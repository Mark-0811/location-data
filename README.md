# Location Data

This repository contains the Odoo 13 location and proper-address module, including its point-in-time location data snapshot.

The current module version is 13.0.2.2.44. The address wizard allows users to enter ZIP codes and preserves a manually entered value when saving an address.

The data snapshot was exported from database `dc20260727` on 6 October 2026. Re-export the CSV files after making location changes that should be included in a future installation.
